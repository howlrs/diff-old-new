- 全 bars: 112
- 日次メンテ bars: 0

> ⚠ **WARNING**: no R3 (CME daily maintenance) bars yet

## 解釈ガイド

- **drift_bps**: メンテ開始時 mid → 終了時 mid の bps. 0 周辺に集中するなら HL 内部 EMA は安定. heavy-tail なら H3 戦略要慎重.
- **post-maint open transitions**: メンテ終了 (18:00 ET) → active 開始 直後の切替で生じるギャップ取りの素材.
- メンテは年 ~250 営業日 → サンプル蓄積が週末の50倍速い.

## 次のステップ

1. 1週間 collect で R3 セグメントが 5+ 取れるはず
2. n_segments ≥ 30 で drift_bps 分布の正規性検定 (Shapiro-Wilk + QQプロット)
3. drift_bps と次 active session 開始 N 分間の return の相関分析
